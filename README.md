## 📌 عن المشروع

نظام **CN AI Core** هو المستودع المركزي لاستعراض ونشر أحدث الواجهات والتطبيقات المتقدمة المصممة عبر **منصة CN AI الذكية**. تم بناء هذه البيئة لتوفير تجربة استعراض ممتازة، سريعة الاستجابة، وتدعم المعايير العالمية لتطوير الويب الحديث.

> 🌐 **رابط المعاينة المباشر:** [CN AI Core Live Showroom](https://cybenodesite-dev.github.io/CN-AI-Core/)  
> 🔗 **منصة الذكاء الاصطناعي:** [CN AI Official Platform](https://ai.cybenode.site/)
